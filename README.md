# Pi Linh — My Little Pink World 🎀

Portfolio cá nhân phong cách pastel pink, dễ thương, responsive cho điện thoại và máy tính.

## Nội dung
- Giới thiệu bản thân
- Sở thích và sở ghét
- Kỹ năng
- Thư viện tác phẩm
- Điều làm Pi Linh vui
- Thông tin liên hệ

## Chỉnh sửa website
Mở file `index.html` trên GitHub và nhấn biểu tượng cây bút để sửa.

1. **Tên và lời giới thiệu:** tìm `Pi Linh`, `Võ Ngọc Phương Linh` hoặc đoạn giới thiệu trong phần `<header>` và `#about`.
2. **Sở thích, sở ghét:** chỉnh các thẻ `<span class="tag">` trong mục `#likes`.
3. **Kỹ năng:** sửa tên kỹ năng và giá trị `--w:82%` trong mục `#skills`.
4. **Thêm tác phẩm:** tạo thư mục `images`, tải ảnh lên đó; thay biểu tượng trong từng `.work-art` bằng:
   `<img src="images/ten-tac-pham.jpg" alt="Mô tả tác phẩm">`
   Sau đó chỉnh tên và mô tả ở `.work-copy`.
5. **Ảnh đại diện:** thay phần biểu tượng `🐰🎀` trong `.portrait-card` bằng thẻ ảnh, ví dụ:
   `<img src="images/avatar.jpg" alt="Ảnh đại diện" style="width:80%;height:80%;object-fit:contain">`
6. **Liên hệ:** thay `hello@example.com`, đường dẫn Instagram và GitHub mẫu bằng liên kết của bạn.
7. **Màu sắc:** sửa các biến ở đầu CSS trong `:root`, ví dụ `--pink`, `--rose`, `--pale`.

## Đưa website lên mạng bằng GitHub Pages
1. Vào **Settings → Pages** của repository.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch **main**, folder **/(root)** rồi nhấn **Save**.
4. Chờ GitHub Pages triển khai xong; URL website sẽ xuất hiện tại mục Pages.
